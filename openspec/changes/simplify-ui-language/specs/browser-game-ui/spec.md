## ADDED Requirements

### Requirement: 初見向けの対局表示
ブラウザUIは内部プレイヤー値、通信処理語、ルール専門語を通常の進行表示へ露出させず、駒を置けるか・次に何を操作するかを日本語で示さなければならない（MUST）。既存の「二人対戦」「ローカル対局へ戻る」の名称と指定された勝利ポップアップ文言は維持しなければならない（MUST）。

#### Scenario: 手番と不正な操作
- **WHEN** 対局中の手番や拒否された着手・パスを表示する
- **THEN** `dark/light`、`合法手`、`要求` といった内部・専門語を通常画面に出さず、プレイヤー側と操作できない理由を示す

#### Scenario: 再接続と記録
- **WHEN** 相手待ち・切断・再接続・対局記録の表示を行う
- **THEN** 重複した状態見出しや通信詳細を減らし、必要な操作と状況を短い日本語で示す

### Requirement: 開発者向け seed の分離
通常画面は再現用 seed 入力を表示せず、新規対局は既定 seed で作成できなければならない（MUST）。手動デバッグ用の明示的な経路では従来の seed 入力を利用できなければならない（MUST）。

#### Scenario: 通常画面
- **WHEN** query parameter なしで画面を開く
- **THEN** seed 入力を表示せず、新しい対局を開始できる

#### Scenario: 手動デバッグ
- **WHEN** `?debug=1` で画面を開く
- **THEN** seed 入力を表示し、0〜4294967295 の値で新規対局を再現できる

### Requirement: 色を駒と目盛りで示す
次に置く駒の色は円形プレビューを主とし、0〜255 の生数値を常時表示してはならない（MUST NOT）。終局時は全駒の色合計を駒数で割った平均値について、白255を左・黒0を右に置いた目盛り上へ平均色で塗った円形の駒を線形配置しなければならない（MUST）。この表示用平均値や丸めを勝者判定へ使用してはならない（MUST NOT）。

#### Scenario: 終局前
- **WHEN** 対局が進行中である
- **THEN** 次の駒色はプレビューで示し、平均色の目盛りと数値・駒数を表示しない

#### Scenario: 終局と端の色
- **WHEN** 終局盤面の平均色が0、255、またはその間の値になる
- **THEN** 駒を実際の平均色で塗り、0は右端、255は左端、中間値は比例した位置へ置き、狭い画面でも駒を欠けさせない
