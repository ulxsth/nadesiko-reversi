## MODIFIED Requirements

### Requirement: 二人対戦の確定状態と拒否の表示
二人対戦UIは受信した確定state全体で盤面を置き換え、担当席の手番にだけ着手・パスを許可しなければならない（MUST）。拒否された操作は盤面を変えずに日本語の理由を表示しなければならない（MUST）。ただし`stale_turn`は同期用stateを適用して通常の競合として扱う。サーバーが理由つきで切断した場合はその理由を表示し、再接続の操作を示さなければならない（MUST）。再接続しても元の対局へ戻れなかった場合、失われた対局の盤面を進行中として表示してはならない（MUST NOT）。

#### Scenario: 交互の着手
- **WHEN** 黒の合法手が受理され、続いて白の合法手が受理される
- **THEN** 両ブラウザに各手の同じ確定盤面、手番、次の駒色を表示する

#### Scenario: 不正手
- **WHEN** 現在の席で許可されない着手またはパスが拒否される
- **THEN** 送信者だけに日本語の拒否理由を表示し、両ブラウザの確定盤面は変化しない

#### Scenario: 古い手番からの送信
- **WHEN** 送信したcommandが`stale_turn`で拒否される
- **THEN** エラー表示を増やさず、返された現在stateで表示を追いつかせる

#### Scenario: 切断と再接続
- **WHEN** 対局中のブラウザが一度切断され、相手が接続中に同じ参加者として再接続する
- **THEN** 切断と復帰を表示し、復帰側は現在state全体を受け取って担当席を維持する

#### Scenario: 理由つきの切断
- **WHEN** サーバーが混雑、アイドル上限、接続時間上限、終了のいずれかの理由を添えて接続を閉じる
- **THEN** その理由を日本語で表示し、再接続の操作を示す

#### Scenario: 復帰できない対局
- **WHEN** 再接続した結果、対局が失われて相手待ちからやり直しになる
- **THEN** 前の対局が終了したことを示し、失われた盤面を進行中として残さない
