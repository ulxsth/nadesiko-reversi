## 表示の境界

変更は #46 が専有する web ファイルと手動確認文書に閉じる。Go 側の state・error code とルール結果は正本のまま維持し、ブラウザで人に見せる語だけを置き換える。状態を失ったときの内部エラー内容は必要に応じて見せるが、通常進行では通信詳細を前面に置かない。

「二人対戦」「ローカル対局へ戻る」と勝利ポップアップの既定文言は変えない。手番は内部 `dark/light` を「先手（黒側）／後手（白側）」として表示し、駒の濃淡とプレイヤー側を区別する。

## 平均色の目盛り

終局盤面で `sum/count` をブラウザ表示用に計算する。白 255 を左、黒 0 を右に置くため、駒中心の位置は `(255 - average) / 255 * 100%` とする。駒の塗りは `rgb(average, average, average)` とし、勝者の判定にはこの表示用平均値を使わない。横軸の左右に駒半径分の余白を取り、0/255でも駒が切れないようにする。数値は画面に常時出さず、アクセシビリティ向けの meter 値だけ保持する。

## 開発者入力

seed 入力は通常表示では `hidden` にする。URL の `?debug=1` を付けた場合だけ既存入力を見せる。入力と seed の契約は変えないため、手動デバッグの再現手順を更新する。新規対局ボタンは通常画面に残し、既定値の seed で動く。

## 検証

OpenSpec strict validation と WSL `make check` を実行する。ブラウザでの最終的な見え方と二画面の操作は人間の手動確認に引き継ぎ、恒常的な E2E は追加しない。
